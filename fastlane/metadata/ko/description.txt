Talkie는 혼자 이동하는 순간의 불안을 덜기 위해 자연스러운 가상 통화를 제공하는 iPhone 앱입니다.

미리 준비된 대화를 선택하고 통화를 시작하면, 사용자의 말하기와 무음 구간에 맞춰 상대방의 다음 음성이 재생됩니다. 홈 화면 위젯을 추가하면 앱을 찾는 시간을 줄이고 가상 통화를 빠르게 시작할 수 있습니다.

주요 기능
• 상황에 맞게 선택할 수 있는 가상 통화 시나리오
• 사용자 발화와 연속 무음을 감지하는 자연스러운 대화 진행
• 홈 화면 위젯을 통한 빠른 통화 시작
• 통화 화면에서 보호자에게 현재 위치 공유
• 통화 화면에서 112 문자 및 전화 실행
• 선택 가능한 자동 녹음과 통화 내역 관리
• 사용자 선택에 따른 개인 iCloud 동기화

마이크 입력은 음성의 시작과 끝을 판정하고, 자동 녹음을 켠 경우 사용자 목소리와 주변 소리를 저장하는 데 사용됩니다. 음성을 문자로 전사하지 않습니다. 위치는 사용자가 위치 공유 또는 신고 기능을 직접 실행할 때만 요청합니다.

Talkie는 실제 보호, 범죄 예방 또는 긴급 구조를 보장하지 않습니다. 즉각적인 위험 상황에서는 112에 직접 신고하고 주변의 도움을 요청하세요.
