개인정보 처리방침

Talkie는 앱 기능에 필요한 데이터를 기기 안에서 처리하며, 사용자가 선택한 경우에만 개인 iCloud 동기화를 사용합니다. 개발자가 운영하는 별도 서버로 사용자 데이터를 전송하지 않습니다.

마이크와 발화 감지녹음위치와 메시지iCloud수집 및 추적사용자 제어방침 변경문의

1. 마이크와 발화 감지

Talkie는 가상 통화 중 사용자가 말하는 구간과 연속 무음 구간을 판정하기 위해 마이크 입력을 사용합니다. 이 처리는 기기 안에서 이루어지며 음성을 문자로 전사하지 않습니다.

2. 자동 녹음

자동 녹음은 사용자가 설정에서 직접 켠 경우에만 동작합니다. 녹음에는 사용자 목소리와 주변 환경음이 포함될 수 있으며 앱의 로컬 저장 공간에 보관됩니다. 사용자는 앱에서 녹음을 재생하거나 삭제할 수 있습니다.

3. 위치와 메시지

위치는 사용자가 통화 화면에서 위치 공유 또는 112 메시지 기능을 실행할 때만 요청합니다. Talkie는 현재 좌표로 지도 링크를 만들고 iOS의 메시지 작성 화면에 넣습니다. 메시지는 자동 전송되지 않으며 수신자, 내용과 전송 여부는 사용자가 확인합니다.

4. iCloud 동기화

iCloud 동기화는 기본 필수 기능이 아니며 사용자가 직접 켜거나 끌 수 있습니다. 켠 경우 사용자 시나리오, 대사 녹음, 안전 연락망과 사용자가 동의를 확인한 가상 통화 녹음이 Apple CloudKit을 통해 사용자의 개인 iCloud 데이터베이스에 저장될 수 있습니다. 해당 데이터에는 사용자의 Apple 계정과 iCloud 서비스 정책이 적용됩니다.

5. 개발자의 데이터 수집과 추적

Talkie는 광고 SDK나 제3자 분석 SDK를 포함하지 않으며 광고 목적으로 사용자를 추적하지 않습니다. 개발자가 운영하는 별도 계정 시스템이나 사용자 데이터 서버도 사용하지 않습니다.

6. 사용자 제어와 보관

마이크와 위치 권한은 iPhone 설정에서 변경할 수 있습니다. 자동 녹음과 iCloud 동기화는 앱의 마이페이지에서 변경할 수 있으며 녹음과 통화 내역은 앱에서 삭제할 수 있습니다. 앱을 삭제하면 기기에 저장된 로컬 데이터가 제거되지만 iCloud에 동기화된 데이터는 iCloud 상태에 따라 별도로 남을 수 있습니다.

7. 방침 변경

앱의 데이터 처리 방식이 변경되면 이 페이지와 App Store의 개인정보 공개 내용을 함께 갱신하고 새 시행일을 표시합니다.
