# Talkie App Review Notes

Talkie는 사용자가 불안을 느끼는 순간 실제 개인 통화처럼 보이는 가상 통화를 제공한다. 긴급 구조 기관을 사칭하지 않으며 실제 보호, 범죄 예방 또는 안전 보장을 주장하지 않는다. 데모 계정은 필요하지 않다.

심사 시 첫 실행 온보딩을 완료하고 포함된 시나리오 중 하나를 선택한 뒤 통화를 시작한다. 마이크는 음성을 전사하지 않고 발화와 연속 무음을 기기 안에서 판정하는 데 사용한다. 자동 녹음은 사용자가 켠 경우에만 마이크 입력과 주변 소리를 로컬에 저장한다.

iCloud 동기화는 선택 기능이다. 사용자가 직접 켜고 녹음 동기화 안내를 확인한 경우 지원되는 데이터와 녹음을 사용자의 private CloudKit database에 저장한다.

위치 공유와 112 메시지는 사용자가 버튼을 누를 때 위치를 요청하고 지도 링크가 포함된 시스템 메시지 작성 화면을 연다. 앱이 메시지를 자동 전송하지 않는다. 112 전화는 시스템 전화 흐름을 연다.

홈 화면 위젯은 선택한 가상 통화를 빠르게 시작한다. Live Activity와 백그라운드 오디오는 진행 중인 가상 통화 상태를 유지하고 표시하는 데만 사용한다.

영문 제출 원문은 `fastlane/metadata/review_information/notes.txt`를 사용한다.
